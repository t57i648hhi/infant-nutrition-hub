# 【微医讯】血液病医学部成功实施成人非血缘脐带血造血干细胞移植救治急性髓性白血病患者

> 更新时间：2026-09-16 (UTC+8)

//

　　近日，解放军总医院第五医学中心血液病医学部三病区胡亮钉主任医师移植团队成功完成一例高难度成人非血缘脐带血造血干细胞移植，填补了中心在该领域的空白。

　　目前，国内外成人异基因造血干细胞移植物主要来源于外周血及骨髓，而脐带血移植由于干细胞数量相对较少、移植后造血重建难度大等原因并非移植物主流来源。近年来，随着单倍型移植技术的成熟，造血干细胞移植几乎进入到“人人有供者”时代，但仍有少部分患者无法寻找到合适的外周血或骨髓造血干细胞移植供者。因此，对于这部分患者，脐带血移植或许是治愈疾病的唯一选择。

　　一年前，第五医学中心血液病医学部血液科三病区收治了一名来自山东的女性患者，诊断为“急性髓性白血病（AML 高危）”，患者病情持续进展，实施移植刻不容缓。然而，移植团队在为患者寻找供者的过程中却遇到了困难，亲缘和无关供者中均未能找到合适外周血及骨髓配型。移植团队并未就此放弃，积极尝试为患者联系脐带血配型。最终，在北京市脐血库查找到一份合适的非血缘脐带血造血干细胞。
　　在胡亮钉主任医师的带领下，成立了以李欲航副主任医师为中心的移植小组，精心准备，反复论证，并与患者及家属充分沟通。最终决定实施非血缘脐带血造血干细胞移植救治患者。       

　　移植团队结合患者身体状况、疾病状态及脐带血移植特点，制定了独创性的改良移植方案，积极探索新技术、新疗法的应用。针对患者病情状况，采取个体化预处理方式，并设立了自体骨髓干细胞移植备用方案。5月2日，移植团队为患者启动预处理。5月10日，患者接受非血缘脐带血造血干细胞回输。

　　移植期间，面对超大剂量预处理化疗引起的致死性副作用、漫长粒细胞缺乏期带来的极高感染风险、脐血移植中高发的急性移植物抗宿主病等围移植期并发症，医疗及护理团队精诚合作，给予优化的移植后粒缺期预防感染方案。历时70余天，患者最终以最低的配型相合程度、最低限的干细胞数量顺利完成造血重建，零感染出仓。因超长时间独自处于封闭的层流病房环境内，患者生理、心理承受巨大压力，医护人员轮流及时给予心理疏导，提供了强大的情感支持，坚定了患者治疗成功的信念，使其最终重获新生。

　　学部制改革以来，血液病医学部不断集中力量加强建设，医疗资源配置更加合理，医疗工作运行更加高效。截至目前，血液科三病区已成功完成100余例造血干细胞移植，为广大血液病患者带来了生的希望。
