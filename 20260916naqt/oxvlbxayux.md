# 复发性流产患者，这个检查有必要！

> 更新时间：2026-09-16 (UTC+8)

女性连续发生自然流产2次及2次以上，在妊娠28周之前的胎儿丢失称为复发性流产，也包括连续发生的生化妊娠。复发性流产让女性一次次承受得到失去的痛苦，不仅是对身体的伤害，更是对心理的伤害，到底是什么原因引起复发性流产的呢？
//

近期，我院妇女保健科复发性流产门诊从近3个月所做的宫腔镜检查病例中，随机抽取20份病例，发现约有80%以上患者有不同程度的宫腔病变，发生率远远高于普通人群，主要以子宫内膜炎、宫腔粘连、输卵管堵塞、子宫内膜息肉为主。

我院妇女保健科黄新颜副主任医师表示，复发性流产患者病因复杂，既可能是单一因素导致流产，也可能是混杂的多因素导致。复发性流产的病因有免疫紊乱、血栓前状态、内分泌失调、遗传因素、生殖道畸形、感染因素，其他还有环境因素、生活习惯、营养因素、药物因素、男性因素等，也有部分患者病因未明。

宫腔作为胚胎的“家”，会直接影响胚胎的生长、发育和存活。因而，复发性流产患者有必要了解自己的宫腔环境。

尤其有的女性多次流产及清宫手术后，宫腔容易发生炎症、粘连、形成息肉等病变，使内膜遭到破坏，子宫容积减小，子宫内膜容受性降低，影响胚胎正常着床发育，并导致胎儿难以在宫腔内存活至足月，即便少数可至妊娠足月，也常合并胎盘残留、胎盘植入、产后出血等严重产科并发症。

如果超声发现疑似宫腔粘连、宫腔息肉，或者月经量变少，以及在辅助生殖过程中已对其他病因进行对症治疗依然移植不着床时，建议做宫腔镜检查、子宫内膜活检，一旦确诊宫腔有畸形、粘连、息肉、炎症等情况，及时处理。希望女性重视起来，不要忽略这个可能阻碍成为妈妈的病因！

另外，做宫腔镜检查可收到多重好处，既可直接取内膜标本，做子宫内膜活检，了解是否存在宫内感染或内膜病变的可能，也可进行输卵管插管，检查输卵管通畅度，疏通输卵管间质部阻塞。这样不仅减少了费用，也节省了时间，更降低了宫腔感染的风险。
