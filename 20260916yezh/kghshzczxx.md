# 新闻间丨我院放射科夏爽团队联合多中心研发纳米探针+机器学习技术 精准预警卒中高危斑块

> 更新时间：2026-09-16 (UTC+8)

2026年1月，天津市第一中心医院放射科夏爽教授团队，在纳米科学顶级期刊ACS Nano（中科院1区，IF：16.1）发表题为Predicting Plaque Vulnerability Using Machine Learning-Enabled Nanoagents Sensitized Molecular High-Resolution Magnetic Resonance Imaging Data的突破性研究成果（DOI:10.1021/acsnano.5c17779），首创靶向泡沫巨噬细胞MR纳米探针（tFM-Nanoagents），结合机器学习解码高分辨率血管壁MRI数据，构建nano-AML评分，实现动脉粥样硬化斑块易损性的精准预测，为缺血性卒中早期预警提供了全新的无创诊断范式。

**关键发现**

**纳米探针+机器学习，解锁斑块“脆弱密码”**

泡沫巨噬细胞是驱动动脉粥样硬化斑块破裂的核心因素，精准量化其负荷是斑块风险分层的关键。研究团队研发的 tFM-Nanoagents 以谷胱甘肽包裹的超小金纳米颗粒为核心，表面修饰靶向泡沫巨噬细胞清道夫受体 SR-AI 的 PP1 肽，同时螯合 Gd³⁺赋予 MR 成像功能。静脉注射后，探针可通过特异性识别主动富集于斑块内泡沫巨噬细胞区域，在高分辨率血管壁成像（HR-VWI）上呈现清晰高信号，形成 “探针靶向成像 - 影像特征提取 - 机器学习建模 - 评分量化易损性” 的全新诊断范式。该诊断范式的核心流程如图1所示。

▲图1：纳米探针 + 机器学习预测斑块易损性诊断范式图 tFM-Nanoagents 靶向泡沫巨噬细胞，经 HR-VWI 可视化斑块分布，机器学习筛选影像特征并构建 nano-AML 评分，实现动脉粥样硬化斑块易损性精准量化

**探针靶向特异性优异，纵向监测与3D定位能力突出**

体外与体内实验均验证了tFM-Nanoagents的高靶向特异性，其在泡沫巨噬细胞中的荧光信号为普通巨噬细胞的3.33倍，静脉注射后斑块区域对比噪声比（CNR）从6.50升至48.71，增强效果显著优于商用造影剂Gadovist（钆布醇，商用MR造影剂）。在4-20周高脂饮食模型中，该探针各时间点的斑块CNR均显著高于Gadovist，且与SR-AI表达强相关（R=0.77-0.85）；通过3D重建技术，探针增强区域与油红O染色阳性区域高度一致，可清晰呈现斑块的时空分布，实现斑块进展的精准纵向监测。

体外与体内实验均验证了tFM-Nanoagents的高靶向特异性，其在泡沫巨噬细胞中的荧光信号为普通巨噬细胞的3.33倍（P<0.001），静脉注射后斑块区域对比噪声比（CNR）从6.50升至48.71（P<0.001），增强效果显著优于商用MR造影剂钆布醇（Gadovist）。tFM-Nanoagents 的靶向特异性经体外及体内实验验证，结果如图2所示。

**nano-AML评分精准区分易损/稳定斑块，诊断效能优异**

研究团队从104个斑块影像中提取关键特征，经机器学习筛选出9个与病理易损指数高度相关的特征，构建逻辑回归模型并生成 nano-AML 评分。该模型的构建及诊断效能验证结果如图4所示。

▲图4：nano-AML 评分模型构建及诊断效能验证图 nano-AML 评分模型训练 / 验证队列 AUC 达 0.871/0.870，显著优于商用造影剂 Gadovist，可精准区分易损 / 稳定斑块

模型在训练队列与验证队列的AUC分别达0.871、0.870（均P<0.001），验证队列中敏感度0.750、特异度高达1.000，诊断效能远优于Gadovist（训练/验证队列AUC分别为0.560、0.538）。以0.681为阈值，该评分可精准区分易损与稳定斑块，典型病例中评分结果与病理易损指数高度吻合，突破传统影像肉眼判读的主观局限。

**临床价值**

**无创量化斑块易损性为卒中精准防治提供全新技术支撑**

该技术填补了无症状、非狭窄性易损斑块早期识别的空白，突破传统影像主观评估的局限，将分子成像与 AI 融合实现斑块易损性客观量化，不仅能为卒中高危人群筛查提供精准工具，还能为临床个性化干预策略制定、治疗效果纵向监测提供量化指标，同时为纳米医学与人工智能在心血管疾病诊断领域的融合应用开辟了全新方向，构建了斑块风险无创诊断的新范式，为缺血性卒中的精准防治提供了重要技术支撑。
